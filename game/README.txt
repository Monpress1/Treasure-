MACO Rush (Three.js)

Open index.html in a browser (needs internet for Three.js and fonts from jsDelivr / Google Fonts).
Everything else, including the three character models, is embedded inside index.html.
The models folder holds the original .glb files for reference only.

Controls: swipe or arrow keys / WASD (left, right, jump, slide). F or the rocket button = fly (needs jetpack).
P or Esc = pause.

Progress (coins, keys, purchases, best score) is saved in the browser's localStorage.
